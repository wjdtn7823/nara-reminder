# 어드민 화면 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 필터를 DB 로 옮겨 어드민 화면에서 등록·조회·수정·삭제하고, 배치 실행 이력을 남겨 조회할 수 있게 한다.

**Architecture:** 기존 Spring Boot 앱에 MVC REST API(`/api`)와 `job_run` 기록을 추가하고, 수집 파이프라인은 매 실행 DB 에서 필터를 읽는다. 화면은 `admin/`(React+TS+Vite) 정적 빌드를 `web` 컨테이너(Caddy)가 서빙하고 `/api` 를 app 으로 프록시한다. 인증은 없다.

**Tech Stack:** Kotlin 2.2.20, Spring Boot 3.5.6 (+ starter-web), PostgreSQL 16 + Flyway, JUnit5/MockK/Testcontainers/MockMvc, React 18.3.1, react-router-dom 6.30.6, Vite 5.4.21, TypeScript 5.6.3, Vitest 2.1.9 + React Testing Library 16.3.3, Caddy 2 (alpine), Node 22 (빌드 전용)

**Spec:** `docs/superpowers/specs/2026-10-25-admin-design.md`

## Global Constraints

- 주석·메시지·커밋 본문 한국어, 식별자 영어. Kotlin `!!` 금지. TS `any` 금지, named export, 함수형 컴포넌트 + Hooks.
- 커밋: Conventional Commits, 한국어 본문, 마지막 줄 `Co-Authored-By: <실제 작성 모델> <noreply@anthropic.com>`.
- 식 본문 테스트(`= runBlocking { ... }`)는 `runBlocking<Unit>` 로 쓴다(아니면 JUnit 이 조용히 건너뜀).
- 시각: DB `Instant`(TIMESTAMPTZ), API ISO-8601, 화면 KST 표시.
- 검증: term 값 trim 후 1~100자·공백만 불가, 같은 type 내 대소문자 무시 중복 불가(409). categories 1개 이상. price 0 이상, `priceMin <= priceMax`.
- 오류 응답 본문 `{code, message}`: 400 `INVALID_FILTER` / `BAD_REQUEST`, 404 `NOT_FOUND`, 409 `DUPLICATE`.
- `/api/runs` 기본 size 50, 최대 100, 최신순(`started_at DESC`). job_run 90일 보관, 매일 03:00 KST 정리.
- 인증 없음. app 8080 은 호스트에 publish 하지 않는다. 화면 의존성은 react, react-dom, react-router-dom 만.
- 테스트: `./gradlew test`(Docker 필요), `cd admin && npm test`. 두 Gradle 빌드를 동시에 돌리지 않는다.

## Review Focus

1. **필터가 비면 모든 공고 발송** — 어드민에서 키워드·수요기관을 모두 지우면 기존 규칙상 전 공고가 통과해 메일이 폭주한다. 사용자가 예상할 동작은 "아무것도 안 받음"이 아니라 현재 규칙 유지일 수 있으나, 최소한 화면에 경고가 있어야 한다. → Task 5 `키워드와 수요기관이 모두 비면 경고를 보여 준다`
2. **대소문자만 다른 중복**(`ODA` vs `oda`) — DB UNIQUE 는 대소문자를 구분하므로 서비스 검사가 막아야 한다. → Task 3 `대소문자만 다른 값은 중복으로 거부한다`
3. **수정으로 다른 항목과 같은 값 만들기** — 추가뿐 아니라 수정에서도 409. → Task 3 `다른 항목과 같은 값으로 수정하면 409`
4. **잘못된 JSON/enum**(`type: "FOO"`, 숫자 칸에 문자열) — 500 이 아니라 400 `{code,message}`. → Task 3 `알 수 없는 type 은 400`
5. **job_run 저장 실패가 수집 결과를 망가뜨림** — 이력 저장 실패는 로그만, job_state 는 정상 갱신. → Task 2 `실행 이력 저장이 실패해도 작업 상태는 저장된다`

`filter/FilterService.kt`:
```kotlin
package com.narareminder.filter

import com.narareminder.notice.FilterCriteria
import org.springframework.data.repository.findByIdOrNull
import org.springframework.stereotype.Service
import org.springframework.transaction.annotation.Transactional
import java.time.Clock

@Service
class FilterService(
    private val termRepository: FilterTermRepository,
    private val settingRepository: FilterSettingRepository,
    private val clock: Clock,
) {
    // 수집 파이프라인이 매 실행 호출해 어드민 변경을 다음 수집부터 반영한다
    @Transactional(readOnly = true)
    fun current(): FilterCriteria {
        val terms = termRepository.findAllByOrderByIdAsc()
        val setting = loadSetting()
        fun valuesOf(type: FilterTermType) = terms.filter { it.type == type }.map { it.value }
        return FilterCriteria(
            keywords = valuesOf(FilterTermType.KEYWORD),
            excludeKeywords = valuesOf(FilterTermType.EXCLUDE_KEYWORD),
            agencies = valuesOf(FilterTermType.AGENCY),
            categories = setting.categoryList(),
            priceMin = setting.priceMin,
            priceMax = setting.priceMax,
        )
    }

    private fun loadSetting(): FilterSetting =
        settingRepository.findByIdOrNull(FilterSetting.SINGLE_ROW_ID)
            ?: error("filter_setting 행이 없습니다. V3 마이그레이션을 확인하세요")
}
```

```kotlin
package com.narareminder.job

import org.springframework.data.domain.PageRequest
import org.springframework.data.domain.Sort
import org.springframework.data.jpa.domain.Specification
import org.springframework.web.bind.annotation.GetMapping
import org.springframework.web.bind.annotation.RequestMapping
import org.springframework.web.bind.annotation.RequestParam
import org.springframework.web.bind.annotation.RestController
import java.time.Instant

data class JobRunResponse(
    val id: Long, val jobName: JobName, val startedAt: Instant, val finishedAt: Instant,
    val windowFrom: Instant, val windowTo: Instant, val fetchedCount: Int, val matchedCount: Int,
    val sentCount: Int, val status: JobRunStatus, val error: String?,
)

data class RunPageResponse(
    val items: List<JobRunResponse>, val page: Int, val size: Int, val totalPages: Int, val totalElements: Long,
)

@RestController
@RequestMapping("/api/runs")
class JobRunController(private val repository: JobRunRepository) {

    @GetMapping
    fun list(
        @RequestParam(required = false) job: JobName?,
        @RequestParam(required = false) status: JobRunStatus?,
        @RequestParam(defaultValue = "0") page: Int,
        @RequestParam(defaultValue = "50") size: Int,
    ): RunPageResponse {
        val spec = listOfNotNull(
            job?.let { value -> Specification<JobRun> { root, _, cb -> cb.equal(root.get<JobName>("jobName"), value) } },
            status?.let { value -> Specification<JobRun> { root, _, cb -> cb.equal(root.get<JobRunStatus>("status"), value) } },
        ).fold(Specification.where<JobRun>(null)) { acc, s -> acc.and(s) }
        val pageable = PageRequest.of(page.coerceAtLeast(0), size.coerceIn(1, MAX_SIZE), Sort.by(Sort.Direction.DESC, "startedAt"))
        val result = repository.findAll(spec, pageable)
        return RunPageResponse(
            items = result.content.map { it.toResponse() },
            page = result.number, size = result.size, totalPages = result.totalPages, totalElements = result.totalElements,
        )
    }

    private fun JobRun.toResponse() = JobRunResponse(
        id = requireNotNull(id), jobName = jobName, startedAt = startedAt, finishedAt = finishedAt,
        windowFrom = windowFrom, windowTo = windowTo, fetchedCount = fetchedCount, matchedCount = matchedCount,
        sentCount = sentCount, status = status, error = error,
    )

    companion object {
        private const val MAX_SIZE = 100
    }
}
```

```ts
export class ApiError extends Error {
  constructor(
    readonly status: number,
    readonly code: string,
    message: string,
  ) {
    super(message)
  }
}

interface ErrorBody {
  code: string
  message: string
}

const isErrorBody = (body: unknown): body is ErrorBody =>
  typeof body === 'object' && body !== null && 'code' in body && 'message' in body

export async function request<T>(path: string, init?: RequestInit): Promise<T> {
  const response = await fetch(path, { ...init, headers: { 'Content-Type': 'application/json', ...init?.headers } })
  if (!response.ok) {
    const body: unknown = await response.json().catch(() => null)
    const error = isErrorBody(body) ? body : { code: 'UNKNOWN', message: `요청 실패 (${response.status})` }
    throw new ApiError(response.status, error.code, error.message)
  }
  if (response.status === 204) return undefined as T
  return (await response.json()) as T
}
```

```tsx
import { type FormEvent, useState } from 'react'
import { ApiError } from '../api/client'
import { addTerm, deleteTerm, updateTerm } from '../api/filters'
import type { Term, TermType } from '../types'

interface TermListCardProps {
  title: string
  type: TermType
  terms: Term[]
  onChanged: () => void
}

const SEARCH_THRESHOLD = 10

export function TermListCard({ title, type, terms, onChanged }: TermListCardProps) {
  const [input, setInput] = useState('')
  const [query, setQuery] = useState('')
  const [editingId, setEditingId] = useState<number | null>(null)
  const [editValue, setEditValue] = useState('')
  const [error, setError] = useState<string | null>(null)

  const run = async (action: () => Promise<unknown>): Promise<boolean> => {
    setError(null)
    try {
      await action()
      onChanged()
      return true
    } catch (e) {
      setError(e instanceof ApiError ? e.message : '요청에 실패했습니다')
      return false
    }
  }

  const handleAdd = async (event: FormEvent) => {
    event.preventDefault()
    if (await run(() => addTerm(type, input))) setInput('')
  }

  const handleSave = async (id: number) => {
    if (await run(() => updateTerm(id, editValue))) setEditingId(null)
  }

  const handleDelete = async (term: Term) => {
    if (window.confirm(`'${term.value}'을(를) 삭제할까요?`)) await run(() => deleteTerm(term.id))
  }

  const normalizedQuery = query.trim().toLowerCase()
  const visible = terms.filter((term) => term.value.toLowerCase().includes(normalizedQuery))

  return (
    <section className="card" aria-label={title}>
      <h2>
        {title} <span className="count">{terms.length}</span>
      </h2>
      <form className="row" onSubmit={handleAdd}>
        <input aria-label={`${title} 입력`} value={input} onChange={(e) => setInput(e.target.value)} placeholder="추가할 값" />
        <button type="submit">추가</button>
      </form>
      {terms.length > SEARCH_THRESHOLD && (
        <input aria-label={`${title} 검색`} value={query} onChange={(e) => setQuery(e.target.value)} placeholder="목록에서 검색" />
      )}
      {error && (
        <p role="alert" className="error">
          {error}
        </p>
      )}
      <ul className="terms">
        {visible.map((term) => (
          <li key={term.id}>
            {editingId === term.id ? (
              <>
                <input aria-label={`${term.value} 수정`} value={editValue} onChange={(e) => setEditValue(e.target.value)} />
                <button type="button" onClick={() => handleSave(term.id)}>
                  저장
                </button>
                <button type="button" onClick={() => setEditingId(null)}>
                  취소
                </button>
              </>
            ) : (
              <>
                <span>{term.value}</span>
                <button
                  type="button"
                  onClick={() => {
                    setEditingId(term.id)
                    setEditValue(term.value)
                  }}
                >
                  수정
                </button>
                <button type="button" onClick={() => handleDelete(term)}>
```

```tsx
import { type FormEvent, useState } from 'react'
import { ApiError } from '../api/client'
import { updateSettings } from '../api/filters'
import { CATEGORIES, CATEGORY_LABELS, type Category } from '../types'

interface SettingsCardProps {
  categories: Category[]
  priceMin: number | null
  priceMax: number | null
  onSaved: () => void
}

const toNumber = (text: string): number | null => (text.trim() === '' ? null : Number(text))

export function SettingsCard({ categories, priceMin, priceMax, onSaved }: SettingsCardProps) {
  const [selected, setSelected] = useState<Category[]>(categories)
  const [min, setMin] = useState(priceMin?.toString() ?? '')
  const [max, setMax] = useState(priceMax?.toString() ?? '')
  const [error, setError] = useState<string | null>(null)
  const [saved, setSaved] = useState(false)

  const toggle = (category: Category) =>
    setSelected((prev) => (prev.includes(category) ? prev.filter((c) => c !== category) : [...prev, category]))

  const handleSubmit = async (event: FormEvent) => {
    event.preventDefault()
    setSaved(false)
    const priceMinValue = toNumber(min)
    const priceMaxValue = toNumber(max)
    if (selected.length === 0) return setError('업무구분을 하나 이상 선택하세요')
    if (priceMinValue !== null && priceMaxValue !== null && priceMinValue > priceMaxValue) {
      return setError('최소 가격이 최대 가격보다 클 수 없습니다')
    }
    setError(null)
    try {
      await updateSettings({
        categories: CATEGORIES.filter((c) => selected.includes(c)),
        priceMin: priceMinValue,
        priceMax: priceMaxValue,
      })
      setSaved(true)
      onSaved()
    } catch (e) {
      setError(e instanceof ApiError ? e.message : '저장에 실패했습니다')
    }
  }

  return (
    <section className="card" aria-label="업무구분 · 가격">
      <h2>업무구분 · 가격</h2>
      <form onSubmit={handleSubmit}>
        <fieldset className="row">
          <legend>업무구분</legend>
          {CATEGORIES.map((category) => (
            <label key={category}>
              <input type="checkbox" checked={selected.includes(category)} onChange={() => toggle(category)} />
              {CATEGORY_LABELS[category]}
            </label>
          ))}
        </fieldset>
        <div className="row">
          <label>
            최소 가격
            <input type="number" min={0} value={min} onChange={(e) => setMin(e.target.value)} />
          </label>
          <label>
            최대 가격
            <input type="number" min={0} value={max} onChange={(e) => setMax(e.target.value)} />
          </label>
        </div>
        <button type="submit">저장</button>
      </form>
      {error && (
        <p role="alert" className="error">
          {error}
        </p>
      )}
      {saved && <p role="status">다음 수집(최대 5분)부터 적용됩니다</p>}
    </section>
  )
}
```

```ts
import type { JobName, JobRun, Page, RunStatus } from '../types'
import { request } from './client'

export interface RunQuery {
  job: JobName | ''
  status: RunStatus | ''
  page: number
}

export const fetchRuns = ({ job, status, page }: RunQuery): Promise<Page<JobRun>> => {
  const params = new URLSearchParams({ page: String(page), size: '50' })
  if (job) params.set('job', job)
  if (status) params.set('status', status)
  return request<Page<JobRun>>(`/api/runs?${params.toString()}`)
}
```
